# MEDSPACE — الجزء 1 (الأساس: الحسابات والصلاحيات)

ما يعمل في هذا الجزء فعليًا: شاشة البداية باسمك، تسجيل الدخول وإنشاء الحساب،
طلبات الانضمام (قيد المراجعة / مقبول / مرفوض / موقوف)، حسابك كمدير وحيد،
شاشة إدارة الطلاب، صفحة "عن التطبيق"، العربية RTL، خط Tajawal، الوضع الليلي/النهاري تلقائيًا.
المواد والـ PDF والمحاضرات تأتي في الأجزاء التالية.

## الخطوة 1 — Supabase (مجاني، بدون بطاقة)
1. أنشئ حسابًا في supabase.com ثم New project (اختر أي اسم وكلمة مرور لقاعدة البيانات).
2. من القائمة: Authentication → Sign In / Providers → Email → أوقف خيار **Confirm email** واحفظ.
3. افتح ملف `supabase_setup.sql`، غيّر `PUT_YOUR_EMAIL_HERE` إلى بريدك، الصقه في SQL Editor واضغط Run.
4. من Project Settings → API انسخ **Project URL** و **anon public key**.
5. افتح الملف `app/src/main/java/com/medspace/app/data/Config.kt` وضع القيمتين مكان `PUT_...`.
   (لا تضع أبدًا مفتاح service_role.)

## الخطوة 2 — بناء الـ APK على GitHub
1. أنشئ حسابًا في github.com ثم مستودعًا جديدًا **Public** باسم medspace.
2. ارفع كل ملفات هذا المجلد (Add file → Upload files) مع المجلد المخفي `.github`.
3. تبويب Actions: سيعمل "Build APK" تلقائيًا (5–10 دقائق). إن ظهر خطأ أحمر انسخ لي نص الخطأ.
4. عند النجاح: تبويب Releases (يمين صفحة المستودع) → حمّل `MEDSPACE.apk`.
   الرابط الثابت لآخر نسخة: `https://github.com/اسمك/medspace/releases/latest/download/MEDSPACE.apk`
5. على الهاتف: افتح الملف واسمح بالتثبيت من هذا المصدر.

## ملاحظات صريحة
- النسخة الحالية موقّعة بمفتاح تطوير (debug) وليست Release نهائية؛ نضيف مفتاح توقيع ثابتًا قبل التسليم النهائي.
- لم تُجرَّب على جهاز بعد؛ قد يلزم تصحيح أخطاء بناء بسيطة في أول مرة.
- المستودع Public ليعمل رابط التحميل بدون تسجيل دخول؛ الكود ظاهر لكن بياناتك محمية بقواعد قاعدة البيانات.
